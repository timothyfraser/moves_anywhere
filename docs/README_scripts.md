# Scripts guide

Part of the MOVES Anywhere guides: see the [index](README.md).

Generated by moves_anywhere/dev/make_scripts_index.R from the script headers. Do not edit by hand: edit the header in the script, then re-run.

This guide lists 56 scripts in `moves_anywhere/scripts/`.

## The run, step by step

`launch.sh` is the entry point; the steps below are in the order it runs them.

| Step | Script | What it does | Reads | Writes |
| --- | --- | --- | --- | --- |
| all | `launch.sh` | A script to run MOVES ANYWHERE at launch. Checks MOVES_IO, then runs every step of a run in order (steps 1 to 16 below): fetch inputs (ticket/sync), check and adapt inputs, build and import the custom database, run MOVES, postprocess, compress, pack, push (ticket/sync). | MOVES_IO (mounted \| ticket \| sync), TICKET_URL, MOVES_PACK, /cat/inputs | /cat/inputs/.timings, /cat/run/stop_reason; each step writes its own outputs |
| 1 | `task_fetch_inputs.sh` | Ticket mode: download this run's inputs into /cat/inputs (docs/RUN_TICKET.md section 3). Gets the run ticket from $TICKET_URL, checks it, then downloads each input it lists, checking size and sha256. In sync mode, copies $MOVES_SYNC_REMOTE/in with rclone. Never prints a URL's query string. | $TICKET_URL (the run ticket) and each input URL in it; $MOVES_SYNC_REMOTE/in in sync mode | /cat/run/ticket.json, /cat/inputs/<name>; /cat/run/stop_reason and ticket.err on failure |
| 2 | `task_check_inputs.sh` | Script to quality check the inputs/ folder before proceeding with MOVES. Only start MOVES if required files are in place. Checks that /cat/inputs exists and holds rs_custom.xml. | /cat/inputs/, /cat/inputs/rs_custom.xml | nothing (prints to the log) |
| 3 | `task_copy_runspec.sh` | Script to copy runspec from /inputs/ into EPA_MOVES_Model folder. Copies /cat/inputs/rs_custom.xml to /cat/EPA_MOVES_Model/rs_custom.xml; stops if it is missing. | /cat/inputs/rs_custom.xml | /cat/EPA_MOVES_Model/rs_custom.xml |
| 4 | `task_check_packages.R` | Script to check if all necessary packages are installed. Compares a list of needed packages with installed.packages() and prints how many are missing, or "R packages ready." It does not stop the run. The list still includes three Google packages: googleCloudStorageR, googleAuthR, gargle. | the installed R packages | nothing (prints to the log) |
| 5 | `task_start_mysql.sh` | Script to launch MySQL. Starts the mysql service, then waits until mysqladmin ping answers. | nothing | nothing (starts the MySQL service) |
| 6 | `task_adapt.R` | Runs the adapt protocol: adapts the MOVES input tables for this run. Sources adapt_functions.R and each adapt_*.R script, then runs their adapt_*() functions in order on the runspec, from identifiers to climate. Each group runs inside run_adapter(): on an error it writes /cat/run/stop_reason ("adapt failed on <name>: <first error line>"), prints the full error, and exits with status 1. | EPA_MOVES_Model/rs_custom.xml; inputs/; the MOVES default database named in the runspec | adapted tables as files in inputs/ (through the adapt_* scripts); /cat/run/stop_reason if an adapter fails |
| 7 | `task_db_create.R` | Creates the custom input database. Connects to MariaDB and runs CREATE DATABASE IF NOT EXISTS custom. The output database and table schema steps below are commented out. | nothing (connects to the local MariaDB server) | MariaDB database custom |
| 8 | `task_create_importer.R` | Script to create an importer.xml file. Runs create_importer() from importer.R on the inputs/ folder, for normal use in Docker (not the FUSE bucket mount). | inputs/rs_custom.xml, inputs/ input tables (_*.csv), scripts/importer_template.xml | inputs/importer.xml |
| 9 | `task_importer.sh` | Script to import a set of files using an importer.xml. Copies inputs/importer.xml into EPA_MOVES_Model/, then runs the MOVES custom database importer as the mysql user. | /cat/inputs/importer.xml, /cat/EPA_MOVES_Model/MOVESConfiguration.txt | /cat/EPA_MOVES_Model/importer.xml, MOVESConfiguration.txt (edited in place), custom input database |
| 10 | `task_launch_moves.sh` | Script to launch MOVES. Runs the CUSTOM runspec (rs_custom.xml) with MOVES as the mysql user; debug mode (keepDebugData) only when the run opts in. | /cat/EPA_MOVES_Model/rs_custom.xml, MOVESConfiguration.txt, /cat/inputs/parameters.json ("debug") | MOVES output database; EPA_MOVES_Model/moveslog.txt; MOVESConfiguration.txt (edited in place) |
| 11 | `task_postprocess.R` | Task to postprocess MOVES data. Inventory runs: write movesoutput and movesactivityoutput as .csvs, then inputs/data.csv unless it is a randomized training run. Rate runs: write the rate tables. | inputs/rs_custom.xml, inputs/parameters.json, MOVES output database (moves) | inputs/movesoutput.csv, inputs/movesactivityoutput.csv, data.rds, inputs/data.csv; rates: inputs/rateper*.csv, inputs/startspervehicle.csv, inputs/movesrun.csv |
| 12 | `task_copy_logs.sh` | Script to copy logs from MOVES to the inputs/ folder, so that the logs persist in mounted volume after job ends. Copies EPA_MOVES_Model/moveslog.txt to inputs/moveslog.txt. | /cat/EPA_MOVES_Model/moveslog.txt | /cat/inputs/moveslog.txt |
| 13 | `task_summarize.R` | Summarize results quickly for diagnostics. Inventory runs: write CO2e Emissions (98) and Vehicle Population to inputs/diagnostics.txt, or remove it if either output .csv is missing. | inputs/rs_custom.xml, inputs/movesoutput.csv, inputs/movesactivityoutput.csv | inputs/diagnostics.txt |
| 14 | `task_compress_outputs.sh` | Compress the run's outputs (data.csv.gz, moveslog.txt.gz, and the rate tables in rate mode). Keeps every original file. Safe to run twice (it overwrites). replication.tar.xz and run_manifest.json belong to task_pack.sh, not here. | /cat/inputs: data.csv, moveslog.txt, rateperhour.csv, ratepervehicle.csv, rateperdistance.csv, rateperstart.csv, startspervehicle.csv, rateperprofile.csv, movesrun.csv (each only if present) | /cat/inputs/<file>.gz for each file read (via <file>.gz.part) |
| 15 | `task_pack.sh` | Pack step: after the outputs are compressed, write replication.tar.xz a kit that reproduces the run on a stock MOVES install run_manifest.json the run's final record (docs/RUN_MANIFEST.md) into $INPUTS_DIR. Source it (". scripts/task_pack.sh") or run it; it is idempotent: a second run on the same folder produces a byte-identical replication.tar.xz. | Environment (all optional): INPUTS_DIR (/cat/inputs), RUN_ID, MOVES_IMAGE, MOVES_IMAGE_DIGEST, MOVES_COMMIT, MOVES_DIR (/cat/EPA_MOVES_Model), MOVES_DEFAULT_DB (movesdb20241112), MOVES_DEBUG, RUN_STATUS (ok\|failed), RUN_STOP_REASON, RUN_STARTED_AT, RUN_FINISHED_AT. Stage timings are read from $INPUTS_DIR/.timings ("stage seconds"). | $INPUTS_DIR/replication.tar.xz and $INPUTS_DIR/run_manifest.json (the manifest through scripts/manifest_fields.py) |
| 16 | `task_push_outputs.sh` | Ticket/sync mode: store the outputs, then run_manifest.json LAST (docs/RUN_TICKET.md section 4). Never prints a URL's query string. | Env in: PUSH_STATUS (ok\|failed, default ok), PUSH_STOP_REASON (optional), STARTED_AT. Also MOVES_IO, TICKET_URL, MOVES_SYNC_REMOTE, MOVES_RETRY_SCALE, /cat/run/ticket.json, /cat/run/stop_reason, and the outputs in /cat/inputs. | the outputs and run_manifest.json to the ticket URLs (ticket) or MOVES_SYNC_REMOTE/out (sync); /cat/run/stored.txt; may rewrite /cat/inputs/run_manifest.json. |

## Failure behaviour

0 if the run finished; 5 if MOVES_IO is unknown or TICKET_URL is missing or not https; 1 if compressing fails, or (mounted mode) if run_manifest.json says failed; the exit status of an R step (4, 6, 7, 8, 11, 13) that fails: the run stops there and writes stop_reason "<step> failed (exit N)" unless the step already wrote one; otherwise the exit code of task_fetch_inputs.sh or task_push_outputs.sh In mounted mode a failed step exits non-zero and prints the reason to the log, and no manifest is written; in ticket/sync mode the pushed failed manifest carries the reason.
