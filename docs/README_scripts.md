| `link_build.R` | turn HPMS road sections into project-scale links (project scale). links_build gives each section a MOVES road type (restricted: functional class 1, and class 2 unless HPMS access_control is 2 or 3; class 2 without access_control is marked default; classes 3-7 are unrestricted whatever access_control says), keeps the sections with a positive count (aadt), joins consecutive equal sections of one route into links of at most 2 miles, and splits a two-way link into a primary and an opposite link with their share of the count. | `link_fill.R` | fill the uncounted roads of a place with the county's remainder traffic (project scale). HPMS gives a daily count (aadt) on most roads but on few local streets. For each MOVES road type r (2 to 5) links_fill computes, for the run's hour, V[r] the county's vehicle-miles from the county tables (month, day, hour, road type shares), C[r] the vehicle-miles already on counted HPMS sections (F[r] x sum(aadt x length)), R[r] = V[r] - C[r] the remainder (0 and a flag "remainder_negative" when counted > county). The unrestricted road types (3 and 5) get one "remainder" link each: length min(uncounted miles in the place, 0.5 x default speed), volume = place remainder / length, grade 0. The restricted types (2 and 4) are never filled; a positive gap is printed as "unplaced". Rule and test cases: docs/audit/project_scale_2026-11/sources/local_roads_fill.md Uncounted miles of the place (the share of the county remainder the place gets, Rb = R x Ub / U): - a county place: U is the county's own uncounted miles, from the saved statistics response (Ub = U, so the place gets all of R); - a box place: Ub is summed from the "uncounted" attribute of links_build() (the sections the builder fetched for the box); U is still the county's, from the statistics response. Switch: fill = FALSE, or the environment variable MA_FILL_REMAINDER=false: no links are added; V, C and R are still computed and printed. | the link builder (task_links.R), after links_build() and links_volume() | through project_read: the county tables (_sourcetypeyearvmt, _monthvmtfraction, _dayvmtfraction, _hourvmtfraction, _roadtypedistribution, _avgspeeddistribution) and the default monthofanyyear and dayofanyweek tables; two HPMS outStatistics requests for the county (counted vehicle-miles and miles; uncounted miles), through links_get() | nothing but the saved responses and requests.csv of links_get; returns the links with the remainder rows appended and attributes fill (table by road type), summary (text lines), sources |
| `link_grade.R` | road grade for project-scale links, derived from federal elevation data. links_grade sends one request per link to the USGS 3DEP ImageServer getSamples (the link's line as an Esri polyline, one sample per 25 m), and sets linkAvgGrade (percent, signed along the geometry) = (median of the last three elevations - median of the first three) / the length they span, (n-3)/(n-1) of the link, x 100. Sets 0 with source "default" and a reason when the link is under 200 m, a end-to-end grade disagrees with the least-squares slope through all samples by over 3 points (an end on a bridge, cut or off the road), the request fails twice, or the response has no usable elevations. Caps at +/- 12. Limits: An odd elevation at one END of a short link may not be caught (the fitted line follows it). The grade is the link's average, so a hill inside a long link is flattened. | the link builder (task_links.R); not part of a county run | https://elevation.nationalmap.gov/arcgis/rest/services/3DEPElevation/ImageServer/getSamples (keyless, federal), or whatever the fetch argument returns in tests | save_dir/NNN_*.json and save_dir/requests.csv, through links_get (link_sources.R) |
| `link_mix.R` | vehicle mix of project-scale links from federal truck counts (HPMS). links_mix gives each link that has both truck counts (aadt_single_unit and aadt_combination) a vehicle mix: the single-unit share goes to source types 52, 53 and 54, the combination share to 61 and 62, each split in proportion to the county default mix of the link's road type; everything else goes to the other vehicle types in proportion to the default mix with those five types removed. ## Failure behaviour

0 if the run finished; 5 if MOVES_IO is unknown or TICKET_URL is missing or not https; 1 if compressing fails, or (mounted mode) if run_manifest.json says failed; the exit status of an R step (4, 6, 7, 8, 11, 13) that fails: the run stops there and writes stop_reason "<step> failed (exit N)" unless the step already wrote one; otherwise the exit code of task_fetch_inputs.sh or task_push_outputs.sh In mounted mode a failed step exits non-zero and prints the reason to the log, and no manifest is written; in ticket/sync mode the pushed failed manifest carries the reason.
